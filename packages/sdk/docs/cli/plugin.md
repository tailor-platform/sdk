## plugin

Manage and inspect CLI plugins (beta).

**Usage**

```
tailor plugin [command]
```

See [Global Options](../cli-reference.md#global-options) for options available to all commands.

**Commands**

| Command                       | Description                                                                              |
| ----------------------------- | ---------------------------------------------------------------------------------------- |
| [`plugin list`](#plugin-list) | List discovered plugins (executables named `<cli>-<name>` on PATH or node_modules/.bin). |

### plugin list

List discovered plugins (executables named `<cli>-<name>` on PATH or node_modules/.bin).

**Usage**

```
tailor plugin list
```

See [Global Options](../cli-reference.md#global-options) for options available to all commands.
