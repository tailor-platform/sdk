# TailorDB Template

Comprehensive TailorDB type definitions demonstrating all features of `db.table()`.

## Features

- All field types (string, int, float, datetime, uuid, enum, boolean)
- Relations (n-1, self-referential)
- Validations (field-level and type-level)
- Hooks (computed fields)
- File attachments
- Composite indexes
- Role-based permissions
- Nested objects
- Timestamps

## Getting Started

```bash
pnpm install
pnpm generate
pnpm deploy
```

## Testing

```bash
pnpm test
```
