# @tailor-platform/sdk-plugin-frontend

## 0.3.0

### Minor Changes

- [#3084](https://github.com/tailor-platform/sdk/pull/3084) [`90482bf`](https://github.com/tailor-platform/sdk/commit/90482bf36c08bceae5ca262f9a10534a6dd16a9e) Thanks [@toiroakr](https://github.com/toiroakr)! - Pass an async function as `build` in `frontendPlugin` to run your own code before the upload, such as writing a runtime configuration file into `dist`. The function receives the deploy context, the `env` values, the absolute `workingDir` and `distDir`, the `profile` `tailor deploy` ran with, `exec` to run shell commands with those values, and `node` (Node.js's `fs/promises` as `fs`, and `pathe` as `path`) for file work, since `tailor.config.ts` cannot import `node:` modules. `onDeployed` hooks of any plugin receive the same `node` in their context. Importing `@tailor-platform/sdk/cli` in `tailor.config.ts` no longer breaks the bundles of functions that run on the Platform.
  
  `@tailor-platform/sdk/cli` also exports `CustomDomainStatus`, the status of a custom domain that `listCustomDomains` returns.

## 0.2.0

### Minor Changes

- [#3141](https://github.com/tailor-platform/sdk/pull/3141) [`edd0fd8`](https://github.com/tailor-platform/sdk/commit/edd0fd8f2572fa55bbcd08766b167cb66ebf47f2) Thanks [@dqn](https://github.com/dqn)! - **Breaking change**: The SDK and its plugins now require Node.js 22 (22.22.2 or later), 24 (24.15.0 or later), or 26 and later, instead of 22.18.0 or later; Node.js 23 and 25 are no longer supported. The CLI's interactive prompt dependencies already required these versions, so Yarn 1, and pnpm with `engine-strict`, could not install the SDK on other versions. Upgrade Node.js to a supported version. On an unsupported version, npm resolves a version range such as `^2.41.0` to an earlier SDK release that supports it, when the range admits one; otherwise, including a bare `npm install @tailor-platform/sdk`, npm installs with an `EBADENGINE` warning, or fails with `engine-strict`.
