Add recovery suggestions to deploy and TailorDB migration failures that had none. `DEPLOY_LOCK_TIMEOUT` names the lock directory to delete when no deploy is running; `tailordb migration rebaseline` refusals over another migration history or a drifted schema suggest `migration set --force` or `migration sync`; a failed post-checkpoint cleanup suggests `migration sync`; `MIGRATION_FILES_INVALID` suggests restoring the files or `migration generate --init`; `tailordb migration test` suggests pulling the latest migrations when the source checkpoint is outside the local history; `deploy` with an unknown workspace ID points at `tailor workspace list`; and prompts that cannot be shown name the option or environment variable to pass instead. An unknown profile now fails with `PROFILE_NOT_FOUND` instead of `UNEXPECTED_ERROR` under `--json`, and suggests `tailor profile list`. `prompt.confirm`, `prompt.text`, `prompt.password`, and `prompt.select` from `@tailor-platform/sdk/cli` accept `suggestion`, reported when the prompt cannot be shown.
