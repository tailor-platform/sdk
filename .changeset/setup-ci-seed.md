Seed the workspace from the generated deploy workflows: `tailor setup ci branch`, `tag`, and `preview` take `--seed` and `--seed-dataset <name>` (repeatable, implies `--seed`), which add a `tailor-seed` step after the deploy step. Branch and tag targets validate the selected data with `tailor seed validate --upsert` before deploy and apply it with `tailor seed apply --upsert` after deploy. Branch targets also validate in the PR or dry-run plan job; tag targets use the plan job's validation before deploy. Preview workspaces validate the data after deploy and apply it with `--truncate --yes`. Setup stops when the config has no `seedPlugin`, `seedPlugin` has no `machineUserName` or `distPath`, the seed data directory is missing, or a dataset is unknown, and seeding is available for targets that deploy one app. `tailor setup update` keeps the flags, and `tailor setup check` reports a seeding target whose `seedPlugin` settings no longer allow it.
