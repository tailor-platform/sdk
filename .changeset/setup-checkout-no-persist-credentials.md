Workflows generated by `tailor setup ci` no longer leave the GitHub token in `.git/config`: every checkout sets `persist-credentials: false`, so dependency install scripts and other project code run by the plan, deploy, and preview jobs cannot read it. The plan and tag guard steps pass the job token only to the `git fetch` they need. Re-run the setup command for each target to pick this up; `tailor setup check` reports a template-version finding until then.
