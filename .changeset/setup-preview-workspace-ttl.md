The preview workflow generated by `tailor setup ci preview` now gives each per-PR workspace a 7-day expiry (`ttl: 7d` on `tailor-preview-deploy`) that every push to the pull request restarts. When a pull request is closed, `tailor-preview-cleanup` also deletes the other expired preview workspaces of the same workspace name in the folder (`TAILOR_PLATFORM_FOLDER_ID`, or directly under the organization when unset), so a preview whose own cleanup never ran no longer stays forever. You can edit `ttl` and re-running `tailor setup` keeps your value.

Run `tailor setup update` to add this to an existing preview workflow. After that, a pull request left idle for more than 7 days has its workspace deleted while it is still open, and the next push creates a fresh one, so the data reviewers added to it is lost. The generated workflows now use `tailor-platform/actions` v2.6.0.
