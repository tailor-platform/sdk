Add `tailor function scaffold`, which scaffolds a one-off script to run with `function run`, and deprecate `tailor function script`. `scaffold` takes the same arguments and behaves as `script` did, matching `tailor workflow scaffold`. `script` keeps working as an alias that prints a deprecation warning, and is removed in v3. A `db.ts` written by `function script` is still refreshed when you scaffold over it, and the file now says `Generated by tailor function scaffold`. `tailor upgrade` offers the `v3/function-script-rename` codemod to rewrite `function script` invocations in package.json scripts, shell scripts, YAML, Markdown, and commands written as strings in TypeScript and JavaScript files.
