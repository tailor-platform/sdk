Add `copilot`, `claude`, and `codex` to `tailor setup ci autofix --codemod`. Each works as `deterministic`, then hands what the codemods leave for review, with their migration prompts, to that AI coding agent in a job of its own, `tailor-codemod-agent`, which installs and runs none of the project's code. The fix commit carries the agent's edits as `chore: apply the SDK upgrade with <agent>`, leaving out `.github/workflows` and, with `claude`, the configuration files claude-code-action resets; if the agent fails, it carries only the codemods' rewrites. The agent runs on each push to a pull request from the repository while changes for review remain, except right after the workflow's own fix commit and for bots other than `renovate[bot]`; the warnings keep listing every change that was left for review. Claude and Codex read an API key from the `TAILOR_AUTOFIX_ANTHROPIC_API_KEY` or `TAILOR_AUTOFIX_OPENAI_API_KEY` repository secret. Copilot reads a fine-grained personal access token from `TAILOR_AUTOFIX_COPILOT_TOKEN`, or, with `--copilot-auth github-token`, signs in with the workflow token. `tailor setup ci env` lists the secret, and `tailor setup update` keeps both flags. With `autofix-ci` and `securefix`, an agent value moves the service's commit into the `tailor-autofix-push` job.
