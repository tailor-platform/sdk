Create a minimal Tailor SDK project for creator profiles in TailorDB.

Each profile should store a public handle that cannot be duplicated and is easy to look up, a display name, an avatar label stored as ordinary profile data, an uploaded avatar image, a list of topical tags, and the time the profile was created. A reviewer should be able to inspect the source and tell which values are regular record fields and which values are uploaded assets.

Keep the implementation small and leave the finished project files in this workspace.
